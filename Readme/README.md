# 🚗 AutoPrime Veículos

Site institucional de uma loja automotiva fictícia, desenvolvido como projeto de estudo e portfólio na área de desenvolvimento web.

O projeto apresenta uma interface moderna, responsiva e interativa para divulgação de veículos, com recursos de pesquisa, filtros, favoritos e contato direto com a loja.

## 📌 Sobre o projeto

A **AutoPrime Veículos** foi criada com o objetivo de praticar e desenvolver habilidades em HTML, CSS e JavaScript, aplicando conceitos utilizados no desenvolvimento de páginas web.

A proposta é simular o site de uma concessionária, oferecendo uma experiência simples e organizada para que os visitantes possam conhecer os veículos disponíveis e encontrar informações sobre cada automóvel.

## 🛠️ Tecnologias utilizadas

- HTML5 — estruturação do conteúdo.
- CSS3 — estilização e layout.
- JavaScript — funcionalidades e interatividade.
- Flexbox — organização dos elementos.
- CSS Grid — estruturação dos cards.
- LocalStorage — armazenamento dos veículos favoritos no navegador.
- Design responsivo — adaptação para diferentes tamanhos de tela.

## ✨ Funcionalidades

- Página inicial com apresentação da loja.
- Catálogo de veículos.
- Cards com imagens, preços e informações dos automóveis.
- Pesquisa de veículos por nome ou modelo.
- Filtros por marca, ano, transmissão e preço.
- Ordenação dos veículos.
- Sistema de favoritos.
- Salvamento dos favoritos no navegador.
- Janela de detalhes dos veículos.
- Galeria de imagens preparada para múltiplas fotos.
- Contato direto pelo WhatsApp.
- Menu responsivo para dispositivos móveis.

## 🎨 Design

O visual da AutoPrime foi desenvolvido com uma identidade moderna e elegante, utilizando:

- Tema escuro.
- Detalhes em dourado.
- Cards com bordas arredondadas.
- Efeitos de transição e `hover`.
- Organização visual com foco na experiência do usuário.
- Layout adaptável para computadores, tablets e celulares.

## 🚀 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
4. Explore as funcionalidades do site.

Também é possível utilizar a extensão **Live Server** do VS Code para visualizar as alterações em tempo real.
